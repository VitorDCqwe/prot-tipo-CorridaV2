Protótipo de jogo de corrida de carro para 2 jogadores

---
## 📚 Aprendizados
- Criação de protótipo de jogos


## ⚙️ Funcionalidades
-Aperte as setas para mover o Jogador Azul e use WSD para mover o Jogador Verde
- Não bata nas barreiras
- Chegue até a linha vermelha para ganhar o jogo

## 🛠️ Stack
- JavaScript
- HTML5
- CSS3

## 🚀 Deploy
1. Clone ou baixe este repositório.

```bash
git clone https://github.com/VitorDCqwe/prot-tipo-CorridaV2```

2. Abra o arquivo `index.html` em seu navegador.
